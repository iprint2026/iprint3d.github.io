📊 گزارش مصرف
گزارش مصرف کالاها بر اساس کالا، پروژه، دلیل و بازهٔ زمانی. می‌توانید بر اساس کالا (مثلاً «فیلامنت») یا پروژه فیلتر کنید؛ خروجی Excel هم دقیقاً همان چیزی را که فیلتر کرده‌اید می‌دهد.
برای مشاهده، روی بروزرسانی بزنید
⚙️ تنظیمات و راه‌اندازی آنلاین
💾 بکاپ و بازگردانی
بکاپ شامل همه داده‌ها (کالاها، کاربران، درخواست‌ها، دسته‌ها، تنظیمات و سفارش‌های مالی) است. در Google Sheet و هر هفته خودکار روی Google Drive (پوشه iPrint3D-backups) ذخیره می‌شود.
🔄 بازسازی فایل‌های متنی سفارش‌ها
فایلِ متنیِ همه‌ی سفارش‌های قبلی را با فرمتِ جدید و لینکِ پیگیری دوباره می‌سازد. قیمت‌ها، داده‌ها و بقیه‌ی فایل‌ها دست‌نمی‌خورند — فقط فایلِ متن بازنویسی می‌شود. (پیشنهاد: اول یک بکاپ بگیر.)

🌐 آنلاین کردن برنامه — قدم به قدم
۱
ساخت Google Sheet
به sheets.google.com بروید → Sheet جدید بسازید → نام آن را lab-inventory بگذارید → ستون‌های زیر را در ردیف اول بنویسید:
id | code | name | desc | cat | qty | unit | shelf | row | minQty | date
۲
ساخت API با Apps Script
در Sheet → منوی Extensions → Apps Script → کد زیر را paste کنید → Deploy → Web App → Anyone
function doGet(e){ var ss=SpreadsheetApp.getActiveSpreadsheet(); var sh=ss.getSheets()[0]; var data=sh.getDataRange().getValues(); var keys=data[0]; var rows=data.slice(1).map(function(r){ var obj={};keys.forEach(function(k,i){obj[k]=r[i]}); return obj; }); return ContentService.createTextOutput(JSON.stringify(rows)) .setMimeType(ContentService.MimeType.JSON); } function doPost(e){ var ss=SpreadsheetApp.getActiveSpreadsheet(); var sh=ss.getSheets()[0]; var d=JSON.parse(e.postData.contents); sh.appendRow([d.id,d.code,d.name,d.desc,d.cat,d.qty,d.unit,d.shelf,d.row,d.minQty,d.date]); return ContentService.createTextOutput("ok"); }

⚙️ تنظیمات — نرخ‌ها، مواد و رزین ترکیبی
▾
نرخ‌ها روی سرور ذخیره می‌شوند و در محاسبه پنهان می‌مانند. بعد از تغییر، حتماً «ذخیره‌ی تنظیمات» را بزنید تا در قیمت اعمال شود.
دستگاه‌ها — نرخ ساعتی (تومان/ساعت)
مواد پایه — قیمت هر کیلو و چگالی
رزین ترکیبی — قیمت هر کیلو از درصد اجزا
نرخ نیروی کار (تومان/ساعت)
پیش‌فرض‌ها نسخه V323
فاکتور — لوگو و مهر (لینک Google Drive)
عکس لوگو و مهر را در Google Drive آپلود کن و لینک اشتراک هرکدام را اینجا بگذار. تصویرها فقط از سرور و برای ادمین خوانده می‌شوند (در فایل سایت ذخیره نمی‌شوند).
✏️ حالت ویرایش — کد · نرخ‌ها ثابتِ زمانِ همان سفارش است
۱) اطلاعات سفارش
پیش‌فرض: تاریخِ امروز. برای تغییر، روی ویرایش بزن (مثل ۱۴۰۴.۳.۲ یا ۱۴۰۵/۲/۲۳).
۲) ردیف‌های هزینه
۳) پارامترهای سفارش

در فاکتور یک ردیف با عنوانِ پروژه و همین تعداد نوشته می‌شود؛ محاسبات و مبلغِ کل تغییر نمی‌کند.
